# Engineering Principles

Restauranty Platform follows these engineering principles.

## Infrastructure as Code

All cloud resources are provisioned through Terraform.

Manual infrastructure changes are avoided.

---

## GitOps

Git is the single source of truth.

---

## Immutable Infrastructure

Infrastructure changes are version controlled.

---

## Automation First

Manual deployments are avoided.

---

## Security by Default

Secrets are never stored inside source code.

---

## Observability

Every production workload should be observable.

---

## Documentation

Operational knowledge is documented alongside the codebase.
